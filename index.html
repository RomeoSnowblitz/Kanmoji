Welcome!

This app intends to make a universal writing system by applying easy to write and read symbols that are consistent across all languages, allowing you to read a language without ever learning it.

If this is your first time I would recommend starting in either Play (Core Practice) or Draw, as you'll need to get used to how the words are used. Also note that in the top left you can create a Username (changeable at any time).

The Top Bar has all of the tabs that you could need, and you can even customize the UI Color as you feel, change the UI Language to the supported languages, and switch between Light and Dark Mode.

Pages & Features

  • Create - This tab is used for adding new words that may not be in the Dictionary, then you can add symbols that can help describe the word. Example: a white, black, cold, winged animal is very likely to be guessed as a penguin. When finished you can click "Submit Word" to add it to the Dictionary.
  • Draw - Draw is a good way to check and modify any symbols that you may disagree with. If you think you can draw a better representation for an image I encourage you to try it. Note that the look of the symbols is more important to the user to make it easy for them to remember, but the meaning of the symbol is something that cannot change.
  • Dictionary - I've imported a lot of words for 7 languages from a CEFR A1–B2 level. This will give users a huge template of words that need revision and symbol adding. To make it more fun than manual labor is the reason that I added Play. There is almost 1 million words, so the dictionary may take a couple seconds to load.
  • Kanji - Browse the 214 Radicals, the Chinese Hanzi and the Japanese Kanji. Every character is broken down into the radicals and pieces it is built from, along with its readings and meanings. Click a character to see its details, add the ones you want to study to your Starred List, and use Learn to practice them. Any Kanversion you make in Play also shows up in a character's details.
  • Web - A homograph is a word that has the same spelling as another word but has a different sound and a different meaning. Looking at a word alone it's impossible to tell which word you are looking at. Web Search organizes words by their assigned symbols so "lead" (to guide) can have a person symbol, while "lead" (the element) can have the metal symbol.
  • Write - Input or paste a language (note that currently Japanese and Chinese require spaces between words). If the output seems wrong, and you notice that a word is underlined, click on the word and a list hopefully containing the right word will be there; then after all the corrections are made hit "Save Sentence contexts" and the app will remember so that if anyone else types that sentence again it will remember to use the right context.
  • Play - Core Practice is a good way to see how well you remember all of the most important symbols. All games created are a fun way to fill all the dictionaries and their symbols.
  • Learn - Pick a language on the chart to learn its Alphabet, Vocabulary and Sentences through short lessons that start easy and get harder. Words you master turn Golden, and holding right-click on a box or a language shows your stats, like lessons completed and how many words are learned and Golden.
  • Comments - If you find any bugs, or have any questions, or suggestions that you think should be added, changed, or removed, you can write about it here. Other users will be able to reply.
  • Transfers - Currently everything is completely off the grid: there is no server, or internet required to use this app. This means that all of the changes you make can only be seen by you. However if you export a file and then send it to someone else and then they import it, then all of the information will be combined together. I plan to import a lot of feedback from other people and then update the project, then everyone can download and either use that version, or import the new version into their current version (recommended to minimize work loss).
